# WB-01: Surgical bugfix

## Goal

Fix one narrowly-scoped failing behavior from a provided failing test, stack trace, or reproduction. The worker should identify the owning boundary, patch the root cause, and avoid unrelated cleanup.

## Starting point

Parent selects a real bug or seeds a failing regression test before dispatch. The worker receives:

- The failing command and the relevant failure excerpt.
- The expected behavior in one sentence.
- The files that are in scope, if known.

## Allowed scope

Allowed:

- Read the relevant implementation and tests.
- Edit the smallest implementation surface that owns the invariant.
- Add or update one regression test if the failing test is only a reproduction script.

Forbidden:

- Rewriting config, package metadata, lockfiles, or unrelated modules.
- Suppressing the failure without fixing the behavior.
- Broad refactors or formatting-only churn.

## Verification

Required checks:

```bash
npm run test:unit -- <target-test-file>
npm run typecheck
```

If the project or target does not support one command, the worker must say exactly why and run the closest narrower check.

## Scoring notes

This task primarily measures correctness, minimality, and root-cause discipline. Award high scores for a tiny diff that makes the failing test pass and preserves unrelated tests. Penalize speculative edits, skipped verification, or changing the test to match broken behavior.
