# SB-04: Agent discovery and model override map

## Goal

Map where agent definitions are discovered, how scoped priority works, and where model overrides are applied before launching a child process.

## Starting point

Start from `src/agents/`, `src/runs/shared/`, and model/agent selection tests.

## Allowed scope

Read-only inspection of `src/agents/`, `src/runs/shared/`, `src/runs/foreground/`, tests that mention agent selection or overrides, and relevant README sections. Do not edit files.

## Expected evidence

A strong answer should identify the discovery path, builtin/user/project priority, frontmatter parsing, override application point, and one risk around stale settings or scoped collisions.

## Scoring notes

Reward exact file/symbol citations and separation between discovery, selection, and execution. Penalize collapsing all config into one vague “settings” layer.
