# SB-05: Prompt/template packaging impact scout

## Goal

Determine the minimal files that must change when adding a new prompt template plus docs assets that should ship in the npm package.

## Starting point

Use the existing worker bakeoff kit as precedent and inspect packaging/prompt registration surfaces.

## Allowed scope

Read-only inspection of `prompts/`, `docs/worker-bakeoff/`, `test/unit/worker-bakeoff-assets.test.ts`, `package.json`, `CHANGELOG.md`, and related README/package docs. Do not edit files.

## Expected evidence

A strong answer should cite the prompt template location, package `files` inclusion, asset test pattern, changelog/version convention, and any docs or README references that may or may not need updates.

## Scoring notes

Reward minimal-change guidance and explicit non-goals. Penalize broad refactor suggestions, missing package `files`, or failing to notice version/changelog conventions.
