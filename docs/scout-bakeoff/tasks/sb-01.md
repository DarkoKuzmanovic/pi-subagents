# SB-01: Slash command routing reconnaissance

## Goal

Map how a slash-command request reaches subagent execution, producing a read-only handoff for a worker who may need to change slash-command behavior.

## Starting point

Start from `src/slash/` and the extension entry point. The scout should identify the main routing files and where a slash command becomes a subagent tool invocation.

## Allowed scope

Read-only inspection of `src/extension/`, `src/slash/`, `src/runs/foreground/`, tests that mention slash commands, and related docs. Do not edit files.

## Expected evidence

A strong answer should cite concrete files/symbols for command registration, slash parsing/dispatch, execution handoff, and representative integration tests. It should distinguish extension setup from foreground execution.

## Scoring notes

Reward exact paths/symbols and a concise flow. Penalize generic descriptions of slash commands, missing the execution boundary, or suggesting implementation work.
